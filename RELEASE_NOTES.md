# Jenkins + Python workshop: Days 1 and 2

Two 6.5-hour teaching days with theory cards, guided practicals, ordered commands,
expected results, troubleshooting tables, instructor checkpoints, and assessment.

The source includes a SQLite-backed Python task API, 39 tests, CI/release Jenkinsfiles,
Docker images, preflight/smoke/deployment automation, and optional Ansible delivery.

Both jobs were executed successfully on the prepared local Jenkins instance. Tests passed
on Python 3.12/Linux and the local Linux agent, with 88.41% coverage. Real container
checks verified persistence, unhealthy candidate rejection, and post-cutover recovery.

Download the PDF for reading, the HTML for a searchable handout, or the ZIP for the full
portable code/documentation pack. Local credentials and generated reports are excluded.
The repository is public. A timed teacher runbook covers both days, including what to
explain, when to execute commands, expected outputs, student activities, and recovery
diagnostics. Students use their own forks for practice commits.

Docker Hub push, external EC2 delivery, and public webhooks remain documented extensions.
